# 個股頁資訊精簡與視覺改版

沿用 React、Vite、Lightweight Charts 與 GitHub Pages。此版調整資訊順序及呈現，不改寫行情、財報、歷史估值公式、資料來源或排程。

## 頁面內容

- 搜尋與市場切換後，先看價格、成交日期及四項關鍵指標，再看 K 線。
- 新增走勢圖、價格評估、基本面、估值試算、資料查核的頁內導覽。點擊會捲動並移動鍵盤焦點，保留市場／代號網址。
- 合併重複的歷史估值、MA20 位置與基本面結論；移除舊的第二組「估值與均線」卡片。
- 移除全站台股更新橫幅、開發介接文件入口、回補配置及供應商設定說明。舊看盤背景 Provider 已不再掛在入口，避免執行沒有被個股頁使用的更新請求；現有個股頁查詢維持運作。
- 資料完整度、來源清單、EPS 組成、累計財報及長篇公式改為可展開內容。缺漏、無行情、日期與單季／累計標示保留。
- 美股沒有行情時顯示明確空狀態，移除三組「盤前／正常盤／盤後均未提供」空卡；有實際分時段資料才顯示。

## 視覺與操作

統一深藍背景、薄荷綠互動色、數字字級與卡片邊界。台股紅漲綠跌保留，圖表與日均線使用原資料口徑。手機的估值數字改成逐列對齊，避免小數被拆行；較窄螢幕自動調整財報卡片欄數。

保留圖表拖曳游標、鍵盤讀值、日／週／月切換、均線開關、名詞對話框及原始資料表。頁內導覽支援減少動畫偏好；第三方圖表署名與授權連結保留。

## 驗收

- `npm test`：167 項／25 檔通過，包含原有資料與估值模型測試。
- `npm run build:pages`：通過，使用 `/finance-school/` 子路徑啟動。
- Chromium：實測日／週／月、期中 K、拖曳讀值、均線開關、EPS 名詞、章節跳轉、展開計算、零／負 EPS、來源展開、台股與美股搜尋。
- 桌面 1440、iPad 820、手機 390 像素：無頁面橫向溢出。額外檢查 320 像素排版。
- 詳見 [瀏覽器驗收紀錄](dashboard-browser-acceptance.json)。

本機預覽：

```bash
npm ci
npm run dev -- --port 4173
# http://127.0.0.1:4173/#analysis/TW/2330
npm run build:pages
npm run preview:pages
# http://127.0.0.1:4176/finance-school/#analysis/TW/2330
```

既有資料限制維持：未齊備的四季 EPS／公告日／歷史樣本不補值，美股行情與 SEC 自動更新不因視覺改版而啟用。
