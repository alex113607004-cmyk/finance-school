## 計算口徑

1. **日 K 與均線**：全部使用未還原除權息的新台幣普通股價格，成交量為股；不混入 ADR 或還原價。MA5/20/60 先用全部日線算簡單平均，再切顯示根數。來源月份缺漏／更新失敗、無效 OHLCV 或日數不足時不補值。
2. **週／月 K**：曆週週一至週日、曆月。開＝第一交易日開盤，高低＝區間極值，收＝末交易日收盤，量＝逐日相加。以台北目前日期判斷曆週／月是否結束，當期 K 棒淡色並標示「期中」。這與口語 MA5「週線」不同。開頭不足一週／月另標起始截斷。週／月 K 不顯示日均線以免混淆口徑。
3. **可用財報**：季報公告當天可能已收盤，統一採公告**次日**起納入。這比直接使用公告日保守。每筆月末觀察只取其日期當時已可用的連續四季；不允許跳季，不重複加總年度累計欄。
4. **樣本**：固定從 2024/01 開始，逐月累積完整且已結束的曆月最後交易日；不納入本月期中值。月末 PE＝當時未還原收盤 ÷ 當時已公告四季稀釋 EPS。正值有效樣本至少 **24 筆**才適用，零／負 EPS 月份排除並列原因。每一筆均顯示四季、公告日、來源與除法。
5. **百分位**：排序後 h=(N−1)×p，從 0 起算，取相鄰值線性內插。現價參考區間＝最新已公告近四季 EPS × 歷史 PE 的 P25/P75，所有內部計算保留精度，顯示才四捨五入。
6. **自動解讀**：只依已算好的價格、區間、倍數與 MA20 產生。估值位置與均線位置分開；低於歷史區間不等於內在低估，亦無推測未證實的漲跌原因。情境試算標示使用者假設，不更動來源資料。

缺少連續四季、EPS≤0、有效樣本<24、資料口徑未確認、首次公告版本變更、下一季已結束且公司來源本次失敗／查核逾 8 日、行情過舊或月份缺漏時，顯示「暫無適用估值」與原因。官方累計報表期已更新而首次 EPS 尚未核實，也停止估值。

## 更新與本機操作

```bash
npm ci
npm run dev -- --port 4173
# 開啟 http://127.0.0.1:4173/#analysis/2330
npm test
npm run build:pages
```

原始資料更新另外需要 Python 3 與 `pdftotext`（Ubuntu：`sudo apt-get install poppler-utils`；macOS：`brew install poppler`）：

```bash
npm run update:market
npm run update:analysis
```

Node 環境如使用 HTTPS_PROXY，請以 Node 24 的 `NODE_USE_ENV_PROXY=1` 執行更新。執行 GitHub Actions 會每日台北 17:00／21:00 擷取、測試及部署；排程可能延後。進入個股頁重新讀取無快取的分析快照與官方近期日線，財報仍由後端排程查核，沒有把「訪客開啟時間」偽裝成「公司公告時間」。舊月份保留真正擷取時間與原始回應，最近兩月重抓以取得更正。

季報匯入器只接受可核對 EPS 標題、段落、當季期間與日期的第一版新聞稿。遇到新格式或既有 PDF 雜湊變動會停止估值並保留數字，須人工核對後更新版本紀錄。公開財報頁可訪問不代表每種解析格式永遠相同。

公告查核使用明確識別本專案的 HTTP User-Agent；公司 IR 主站拒絕連線時，只嘗試台積公司維護的 `investor.cld.tsmc.com` 公開 IR 網域，保留實際成功網址於 `verificationSources`。GitHub Actions 實測兩個 IR 網域均回覆 403。兩者失敗時保留首次公告快照及真正成功查核時間，頁面顯示明確警示；不以第三方來源冒充公司資料。尚在下一個會計季度內時，沒有更新的完整季度可取代既有四季，仍可依已核實快照驗算；**下一季一結束**，若查核失敗或逾 8 日，便停止估值，直到核實新公告。官方彙總已列新季、PDF 版本變動待審或口徑不明時一律立即停止，不受這項保留機制影響。後續財報更正需人工核對，不宣稱失敗的來源已成功重抓。
