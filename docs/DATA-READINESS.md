# 第一階段：資料狀態與財報回補

本階段新增台美股共用的頁首資料狀態、逐欄查核表與現金流回補進度。現有搜尋、排行、圖表及分析模型繼續沿用。財報回補仍有來源限制與首次公告日缺口；依使用者最新指示先進入第二階段，自選股的功能與驗收見 [WATCHLIST.md](WATCHLIST.md)。

## 已實作

- 在個股頁章節導覽下方，以三組資訊呈現行情、財報、歷史估值；區分可查閱、部分待核對、缺漏、需重新查核及不適用，不用單一百分比分數代表投資可信度。
- 行情與官方本益比資料日不同時直接提醒。歷史模型條件已滿足時，另列同日現價／已核實四季 EPS 的本頁重算倍數；行情卡優先呈現具備驗算條件的同日重算倍數，官方倍數自己的日期與口徑保留於查核表及官方估值區。
- 「查看缺口與來源」會開啟內外層查核區塊，捲至查核表並聚焦，鍵盤也可操作。表格列出數值、單位、期間、公告日、成功查核時間與原始連結；不把擷取日當公告日。
- 近四季 EPS 只接受連續四季、直接稀釋 EPS、可核實原始文件及公告日。既有累計 EPS 不用來填補此欄；零／負 EPS 可作為財報數據查閱，但本益比模型不適用。
- 當官方財報已有較新季度時標記舊 EPS，不將最新部署時間當成新財報。月份與季度有各自的期間，月營收以完整曆月呈現。
- 台股沿用 `cashflowView` 驗證同市場、同公司、同年度累計期間、單位、來源 URL 與 FCF 算式；現金流公告日未知時呈現待核對。台積電已有公司公告單季現金流，因此使用其單季原始資料，和 MOPS 年初累計資料分別呈現。
- 美國公司可顯示已核實 SEC 財報，即使行情缺漏；ETF 分別標記公司財報與本益比模型不適用。SEC 自動抓取仍維持未啟用，不代填聯絡資訊。
- 查核區顯示現金流三項完整的公司數、適用分母、待補數、最近成功及嘗試時間、來源暫停到期日。計數重新經過原有 `cashflowView` 驗證，不將錯期間、錯幣別或錯誤 FCF 算式算成完整。
