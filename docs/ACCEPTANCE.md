- 基本面模型 1.0 提供有條件候選／先觀察／資料不足三種研究結論。自訂財務門檻及估值樣本規則均可展開查閱；不是回測策略或個人適合度判定。
- 金融股、ETF 及未接入美股不套一般業門檻。必要來源老於 72 小時、日期異常、價與估值不同日、財報不同季或關鍵值缺漏時不產生買進候選結論。
- 累計 EPS 沒有年化、沒有用它取代 TTM EPS 計算本益比；比較的是官方正式估值。相對同業倍數未當成內在價值或目標價。
