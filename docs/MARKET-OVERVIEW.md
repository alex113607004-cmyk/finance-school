# 市場總覽

入口：[正式市場總覽](https://alex113607004-cmyk.github.io/finance-school/#overview/TW)。網站頂部可在「個股分析」與「市場總覽」之間切換；根網址、舊個股網址、最近查看與圖表滾輪操作保留。

## 可操作功能

- 直接顯示成交熱門，提供成交量、成交金額兩種排序。
- 漲幅、跌幅、收盤漲停與收盤跌停榜；前四名卡片與每頁 30 筆表格均可點進個股分析。
- 全部市場／上市／上櫃與普通股／ETF／股票＋ETF 篩選；統計跟隨篩選範圍。
- 盤後日期、原始來源、實際查核時間、資料不足及保留舊快照提示。
- 手機表格可在表格內左右捲動，頁面本身不超出螢幕。

此頁僅合併新台幣交易標的，不含外幣 ETF 交易櫃台（代號五碼數字加 C／K）、興櫃、權證、零成交或缺少有效收盤價者；美股仍缺合格公開行情來源，因此未加入排行。熱門代表交易量或金額，不是搜尋人氣或買進建議。

停板榜以有效收盤價等於已核實同日官方停板價判定，**不以 ±9.5% 或 ±10% 近似**。不含盤中曾觸及後打開者。來源標示無一般限制、停板價缺漏、日期不符或收盤超出來源範圍者不進停板榜。

上櫃取前一交易日時只跳過週末及官方明確回覆「無資料／查無資料」的日期；網路錯誤不是休市證明，遇到錯誤就停止日期對齊。缺少新停板價時，只有已保存的**同一交易日**核實版本可保留，且不改寫其來源查核時間。

排名只使用同一交易日與目前官方清單內的普通股、ETF；不同市場日期不一致時，合併榜排除較舊市場並提示，可切換查看其原日期快照。成交量用股或受益權單位顯示，金額為 TWD；漲跌幅依官方漲跌價差與參考價格計算，未知漲跌不算平盤。

## 更新與失敗處理

`npm run update:overview` 由 `scripts/overview-collector.mjs` 依 dated 官方報表產生 `src/generated/market-overview.json`，建置時發布為同源 `market-overview-data.json`。Pages 與可選 Worker 均包含此資產。GitHub Actions 沿用每日台北 **17:00、21:00**，也在推送 main 時更新；PR 只跑離線測試與建置。

每次進入總覽或按「重新整理」會讀最新已發布資產，並不觸發所有訪客各自抓全市場。來源 403／429 立即停止該來源的本次重試；舊資料保留原日期與成功查核時間。取得時間不當成交易時間。若所有來源失敗且沒有既有快照，更新命令失敗而不覆寫檔案。

本次直接抓取時 TWSE 後續回傳 HTTP 403，因此保留已成功核實的 11/18 行情與停板價，前端會提示「上市沿用前次資料」；上櫃同日資料可更新。未繞過來源限制，不能保證下一次來源回應或排程準時。
