# 全市場個股分析

入口：[台股個股分析](https://alex113607004-cmyk.github.io/finance-school/#analysis/2330)。此版取消個股頁的 2330 白名單，以官方股票／公司清單產生搜尋範圍；教材與原有看盤頁保留。

## 範圍與功能

2026-11-17 快照共 **2,789 檔**：上市 **1,392**、上櫃 **1,023**、興櫃 **374**。數量包含官方清單中的 ETF、ETN、特別股、存託憑證及不動產受益證券，不只普通股；也保留暫停交易、尚無有效成交價的公司。後續依來源更新，畫面顯示實際數量。不含權證、個別債券、已下市與海外股票。

- 代號、完整／部分名稱、英文簡稱搜尋；支援臺／台、全形文字及市場前綴。精確代號優先，候選顯示市場與標的類型。
- 上市／上櫃／興櫃篩選、鍵盤選候選、最近查看、`#analysis/6488` 等可分享網址。所有 2,789 個代號都經程式逐一解析，沒有硬編碼可查清單。
- 上市與上櫃：盤後開高低收、正式漲跌價差、成交量、日／週／月 K、MA5/20/60、期中 K 棒、拖曳虛線、方向鍵及原始數字表。
- 已申報基本面：**年初至季末累計基本 EPS**、單月營收年增、一般業毛利率／營業利益率／淨利率、季末負債比率／流動比率，以及官方本益比、股價淨值比、殖利率。各欄列期間、出表日與來源；出表日不當首次公告日。
- 同市場、同產業、同估值日的正本益比分布，排除自己且至少五家。明列財報參考期可能不同；不當自身歷史估值或價格目標。
- 股票切換後立即使用新代號資料，舊請求回來也不覆蓋目前股票。歷史檔與瀏覽器快取會檢查代號、市場及 OHLCV，避免跨股票借值。
- 無成交／來源為零值時顯示未取得有效價，不能把來源的 0 當成便宜價格。查無代號、更新失敗、日線不足、新掛牌與財報缺口各有狀態。

櫃買端點沒有允許本網站的瀏覽器 CORS，因此 GitHub Pages **不讓瀏覽器直接讀櫃買 API**，也不用任意第三方代理。由 GitHub Actions 取得官方日報，存為 `data/universe/tpex-days/`，再建置 `stock-history/TPEX/6488.json` 等按需檔案。每次進站重新取得最新已發布全市場快照，查看上櫃時重查同源歷史檔；這不會觸發新的 Actions，也不宣稱每個訪客都重抓原始財報。

上櫃初始回補 **2026-07-31～11-17，73 個有效交易日**，足以核對一般股票的 MA60。無行情日有官方回應記錄，不以缺交易日填價格。排程重抓最新兩天、更早的已保存日期重用，快取逐日累積至最多 14 個月；初始版本沒有宣稱已具 14 個月上櫃歷史。GitHub Actions 使用歷史資料快取，避免每次向來源回補所有股票月份。

上櫃日報的「成交股數」直接採股，遇到「張／仟股」才乘 1,000；不能對所有櫃買數字一律乘 1,000。日線、週月 K 與均線使用同一未還原價格；ETF 成交量顯示受益權單位，外幣交易 ETF 不假定是台幣或自動換匯。

來源失敗時保留前期財報及其原始擷取時間並提示；無已驗證原始資料就保留缺口。上市櫃轉板前後資料不直接拼接。歷史資料缺漏時停用均線與完整估值，不以補值或模擬圖表掩蓋。

## 重要適用限制

1. **全市場可搜尋，不代表每檔都已核實四季 EPS 與歷史估值。**一般彙總表提供累計基本 EPS，不能直接當單季或近四季稀釋 EPS。缺少首次公告日、連續四季及至少 24 個正值月末樣本時，清楚顯示「暫無適用估值」及原因，另提供官方倍數與已申報財務資料。不由價格／四捨五入的本益比反推 EPS 冒充公告數字。
2. **營業現金流不在本次通用彙總 API 中。**目前只有已核實公司提供數字，其他股票列出缺口與 MOPS 現金流量表入口；不把淨利當現金流。
3. **興櫃僅成交快照與已取得的基本面。**來源為議價成交統計，沒有與上市櫃相同口徑的開盤／收盤日 K，本版不製造 K 線或均線。
4. ETF／ETN／不動產受益證券不套單一公司 EPS 模型；金融業不套一般業毛利與流動比率。特別股、TDR 等若未核實每股口徑，亦不套歷史模型。
5. 即時串流、公開行情展示授權仍未取得，見 [即時行情介接](REALTIME.md)。台積電 IR 在 GitHub 環境回覆 403 的已知限制仍按既有規則揭露；本版沒有將其改稱取得成功。

## 本機與維護

```bash
npm ci
npm run dev -- --port 4173
# http://127.0.0.1:4173/#analysis/6488
npm test
npm run build:pages
```

`predev`／`prebuild:pages` 會從已保存的官方日報重建上櫃 JSON，fresh clone 無須先對來源發出數千個請求即可預覽。

更新全部原始來源：

```bash
npm run update:market
npm run update:analysis   # Python 3 + pdftotext，查核首次季報
npm run update:universe  # 全市場清單、財報及共用上櫃日報
npm run build:pages
```

需要代理的 Node 24 環境可加 `NODE_USE_ENV_PROXY=1`。單獨重建已保存歷史資產：`npm run history:assets`。正式排程維持台北 17:00、21:00，時間可能延後；每項實際交易／報表日期均在頁面顯示。
