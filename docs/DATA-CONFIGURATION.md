FCF 在此定義為營業活動淨現金減現金取得不動產、廠房及設備。不將全部投資現金流當資本支出，也未納入無形資產投資。欄位缺少或支出符號無法確認時，保留該項缺口，不補零。

## 時間、版本與失敗處理

- 查詢包含公司代號、`ys=西元年度+季別`、`quarter=false`。解析器核對回應 `yearseason`、公司、市場、合併欄、幣別／單位及欄列數；來源回到預設的 2020Q2 等錯誤期間會被拒絕。
- **來源沒有首次公告日**。`announcedOn:null`，`pointInTimeEligible:false`。查核日與首次觀察日都不是公告日，絕不轉成歷史估值的可用日。
- 不從本資料推導稀釋 EPS，不用全年減前三季 EPS，不倒推官方本益比分母。多數股票的四季 EPS／24 筆歷史估值樣本仍有缺口。
- 保留原始符號、實際期初／期末、範圍、原始來源、查核時間與回應 hash。觀察到同期間修訂時，保留前版數字／hash，不把新版回填歷史。
- 來源失敗保留原值與原查核時間，不把部署時間當資料時間。HTTP 403／429 停止該次抓取，24 小時內不再發送新請求；不使用代理輪替或其他規避方式。
- Actions cache 保存批次進度，repository 保留可離線建置的已驗證基準。PR 用離線模式；正式排程才抓來源。金融業、興櫃、基金與特別股不在本輪一般業回補範圍。

## 指令與部署

```bash
npm ci
npm run update:financials:offline  # 既有已驗證資料重建，不發網路請求
npm run dev -- --port 4173
npm test
npm run build:pages
npm run preview:pages
# http://127.0.0.1:4176/finance-school/#analysis/TW/2317
```

維護者可在需要更新時執行 `NODE_USE_ENV_PROXY=1 npm run update:financials`。預設上限 12 批；`MOPS_MAX_BATCHES` 可設 1～30。仍遵守快取與封鎖暫停；不提供清除限制以密集重試的選項。離線資料不會增加成功查核時間。

## 使用條件查核

TWSE 官方 OpenAPI 規格連至其使用條款與政府資料開放授權；TPEx 官方規格連至其免責條款。財務比較網站本次可回查指定公司報表，但 `/terms` 在環境中回傳 403，因此**未宣稱取得全面商用或原站鏡像散布授權**。專案保存選定申報事實數字、來源及 hash，不建立原站 HTML 鏡像。若日後擴充為商用大量資料服務，需另確認相應條件。twstock 的 MIT 授權僅涵蓋其程式碼。

## 驗收

自動測試涵蓋真實三檔 FCF、錯誤期間／公司／市場／單位、個體報表、缺值與零值、支出符號、版本修訂、跨市場公平批次、來源失敗保留及 24 小時暫停、介面展開原始算式。部署與瀏覽器結果另見 [瀏覽器驗收](data-configuration-browser.json)。
