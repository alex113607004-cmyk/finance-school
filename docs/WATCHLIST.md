# 第二階段：自選股與返回瀏覽位置

入口：[正式自選股](https://alex113607004-cmyk.github.io/finance-school/#watchlist/all)。使用者已明確指示先進入第二階段；第一階段的財報缺口仍保留，沒有將缺漏改成已完成，也尚未開發第三階段的估值區間圖。

## 功能與使用

- 個股頁行情卡的「加入自選」，以及市場排行表格的星號，可加入或移除標的。支援既有台股範圍、AAPL、MSFT 與 SPY；未涵蓋或不再出現在資料中的舊自選會保留並顯示缺口。
- 頂部「自選股」顯示清單數量；自選頁提供全部／台股／美股、清單內代號或名稱搜尋，以及原個股分析連結。
- 每張卡獨立顯示幣別、行情日期、可核實基本面與原始來源，以及既有歷史模型的估值狀態；EPS、YoY、自由現金流沿用原有指標解釋。只有資料及 24 筆樣本等條件滿足才顯示區間，不從累計 EPS 推算近四季、不補美股價格。
- 每次開啟自選頁或按重新整理，讀取已發布的全市場、研究、美股與排行資產；不為每檔自選額外查 14 個月官方日線。不同來源保留自己的日期，來源失敗保留原日期快照。
- 返回市場總覽，保留市場、普通股／ETF、排行分類、成交量／成交金額、頁碼、頁面縱向位置與表格橫向位置；瀏覽器「上一頁」與頂部導覽均可使用。最新資料筆數改變時頁碼會限縮到有效範圍。
- 自選頁也按市場分開保留清單搜尋與位置。資料尚在載入時會嘗試完成位置還原；一旦使用者操作，就不因後到的資料將畫面拉回。

現價及財報並非同時即時更新。自選頁沿用網站每日台灣時間 17:00、21:00 發布快照，排程與來源可能延後；個股頁原本另查的官方近期日線可能比自選頁的已發布快照新，應比較各自的資料日期。

## 保存、同步與失敗處理

- 清單最多 **100 檔**，身份為 `TW:2330`、`US:AAPL` 等市場加代號。只保存身份、名稱與加入時間，**不將價格、EPS、估值或個人持股成本寫入自選資料**。
- 自選存在 `localStorage` 的 `finance-school.watchlist.v1`。同一瀏覽器同來源的分頁透過 `storage` 事件同步；不同裝置、不同瀏覽器不會同步，也沒有帳號、後端自選資料庫或交易功能。
- 新增前重讀最新清單，儲存失敗時保留這一分頁的操作並明確提示「僅此分頁暫存」。可在允許儲存或釋放空間後按「重試儲存」。重試會合併其他分頁已存的變更，超過 100 檔時要求先移除，不自動淘汰標的。
- 格式損壞時保留原始字串；恢復儲存前先備份至 `finance-school.watchlist.recovery.v1`。備份或儲存失敗時不覆寫原資料，清單仍可在本分頁使用。
- 多分頁正常更新會同步；同一瞬間競爭寫入仍受瀏覽器最後一次寫入規則限制，不宣稱跨分頁資料庫交易一致性。清除瀏覽器資料或私人瀏覽結束可能移除清單。
- 瀏覽偏好另存 `sessionStorage` 的 `finance-school.overview-view.v1` 與 `finance-school.watchlist-view.<market>.v1`。無法使用時保留分頁內記憶並提示，不影響自選清單或原有學習紀錄。

## 現成專案評估與實作選擇

2026-11-19 查核 [usehooks-ts](https://github.com/juliencrn/usehooks-ts) 的 [useLocalStorage](https://github.com/juliencrn/usehooks-ts/blob/master/packages/usehooks-ts/src/useLocalStorage/useLocalStorage.ts) 與 [MIT 授權](https://github.com/juliencrn/usehooks-ts/blob/master/LICENSE)，參考其同分頁通知、跨分頁 storage 事件及讀取異常處理。其通用 hook 將儲存錯誤記錄在 console，無法直接提供本網站所需的明確保存結果、待儲存操作與容量衝突處理。

因此沿用專案已有 React 19，以內建 `useSyncExternalStore` 訂閱封裝的儲存層，沒有新增外部套件，也沒有直接複製該專案程式碼。市場身份、驗證、重試及清單容量屬本站的資料契約。財報及估值則重用原有計算模組，將既有台積電快照組裝函式抽為純函式供兩頁共用，數值口徑保持一致。
