# 滾輪縮放與可見 K 線根數

本次修改僅限價格走勢圖，沿用既有頁面、資料來源與分析模型。

原圖表先把歷史資料截為最後 60 根，再交給 Lightweight Charts；縮小時間軸後無法顯示更早的 K 線。現在畫布載入全部已取得的歷史 K 線，初始視窗仍為最近 60 根。

- 滾輪放大時減少可見根數，縮小時顯示更多已取得資料；不再受初始 60 根限制。
- 「顯示根數」同步呈現實際視窗根數，支援 30／60／120／全部的快速選擇。部分位於畫面邊緣的 K 棒依圖表原生範圍規則計入，不把空白區當成 K 線。
- 日期滑桿、讀值與原始數字表跟隨目前可見範圍。原始表在展開時才建立，避免縮放時反覆繪製數千個隱藏欄位。
- 切換均線保留縮放位置；行情查詢進度更新不會因包裝物件變更而重建圖表。實際歷史資料更新時，以日期對齊保留視窗。
- 日／週／月 K 均支援；根數上限為該週期已取得的資料量。保留原有拖曳虛線及鍵盤選取。

`npm test`、`npm run build:pages` 與 Chromium 實際滾輪操作。單元測試涵蓋完整資料載入、部分邊緣、空白邊界、短歷史、均線重建、歷史更新、選單／滑桿／原始表同步與訂閱清理。

瀏覽器紀錄：[chart-wheel-browser-acceptance.json](chart-wheel-browser-acceptance.json)。驗證放大／縮小、縮小至全部資料、30／60／120／全部、日／週／月、均線、拖曳虛線，以及桌面、iPad 與手機寬度。觸控雙指仍沿用原設定，未聲稱已在實體裝置驗收。
